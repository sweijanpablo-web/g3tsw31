DARK VEIL - HOW TO USE

RUN IT
1. Unzip this folder.
2. Double-click index.html. It opens in your browser. (Needs internet only for the fonts.)

EDIT YOUR CONTENT  -> open script.js in Notepad or VS Code
Everything is in the SITE block at the top:
  name, age, school, course ........ top of SITE
  about text ....................... about
  achievements ..................... achievements
  school history + achievements .... education (add lines inside achievements:[ ... ])
  skills + levels (Beginner, Familiar, Intermediate, Currently Learning) ... skills
  projects ......................... projects (empty now; copy the example line)
  email / GitHub / Facebook / LinkedIn ... contact (empty ones stay hidden)

CHANGE THE PROFILE PICTURE
Replace assets/profile.jpg with your own image (keep the same file name),
or change the photo value in script.js to another file name or image link.

CHANGE COLORS/LOOK -> style.css (colors are at the top, under :root)

PUT IT ONLINE (free): upload the whole folder to GitHub Pages or Netlify.
